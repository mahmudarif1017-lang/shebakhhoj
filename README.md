# সেবাখোঁজ — ShebaKhoj

রাজশাহীর জন্য তৈরি একটি Local Service Discovery Platform-এর MVP প্রোটোটাইপ। সম্পূর্ণ ইন্টারফেস বাংলা ভাষায়।

## প্রযুক্তি

- React 18 + TypeScript
- Vite
- Tailwind CSS
- Lucide Icons
- React Router
- LocalStorage (কোনো ব্যাকএন্ড বা পেইড API নেই)

## লোকালে চালানো

```bash
npm install
npm run dev
```

প্রোডাকশন বিল্ড:

```bash
npm run build
npm run preview
```

## Lovable-এ প্রকাশ করা

1. এই ফোল্ডারের সমস্ত ফাইল Lovable প্রজেক্টে কপি/ইম্পোর্ট করুন (`package.json`, `src`, `index.html`, `.css` কনফিগসহ)।
2. Lovable-এর Preview-এ অ্যাপটি চেক করুন। কোনো environment variable বা API key সেট করতে হবে না।
3. প্রয়োজনে Google Fonts (Hind Siliguri) ইতিমধ্যে `index.html`-এ লিংক করা আছে—কোনো key লাগবে না।
4. Lovable-এর **Publish** বাটনে ক্লিক করে লিংক পান।

## পেইজসমূহ

| রুট | বর্ণনা |
|---|---|
| `/` | হোমপেজ, স্মার্ট সার্চ, ক্যাটাগরি, জনপ্রিয় সেবাদাতা |
| `/services` | সার্চ ও ফিল্টারসহ সেবা আবিষ্কার |
| `/provider/:id` | সেবাদাতার প্রোফাইল, রিভিউ ও যোগাযোগ |
| `/register` | সেবাদাতা নিবন্ধন (localStorage-এ সংরক্ষিত) |
| `/admin` | ডেমো অ্যাডমিন প্যানেল |
| `/about` | আমাদের সম্পর্কে |

## Smart Search

`src/lib/smartSearch.ts` একটি `SearchEngine` ইন্টারফেস সরবরাহ করে। বর্তমান বাস্তবায়ন কীওয়ার্ড-ভিত্তিক ও সম্পূর্ণ নির্ধারক (deterministic)—এটি কোনো এআই মডেল নয়। ভবিষ্যতে প্রকৃত এআই যোগ করতে হলে একই ইন্টারফেস বাস্তবায়ন করে `searchEngine` এর ভ্যালু বদলালেই হবে; অন্য কোনো কম্পোনেন্ট বদলাতে হবে না।

## ডেমো ডাটা ও সীমাবদ্ধতা

- ১২টি সেবাদাতা প্রোফাইল, তাদের রিভিউ ও রেটিং **সম্পূর্ণ কাল্পনিক** এবং ডেমো হিসেবে চিহ্নিত।
- ডেমো প্রোফাইলে বাস্তব ফোন নম্বর নেই—তাই ফোন/WhatsApp বাটন সেখানে নিষ্ক্রিয়।
- নতুন নিবন্ধন সবসময় "অনুমোদনের অপেক্ষায়" থাকে; স্বয়ংক্রিয় যাচাই হয় না।
- ডেমো অ্যাডমিন প্যানেলে কোনো নিরাপদ লগইন নেই এবং অনুমোদন কোনো বাস্তব পরিচয় যাচাই নয়।
- রিভিউগুলো ডেমো জমা—কোনো কেনাকাটা বা সম্পন্ন কাজের প্রমাণ নয়।
- সমস্ত ব্যবহারকারী-জমা তথ্য শুধু বর্তমান ব্রাউজারের localStorage-এ থাকে; ব্রাউজার ডাটা মুছলে চলে যাবে।
